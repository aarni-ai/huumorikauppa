**Miksi tilata Huumorikaupasta?**
- Ilmainen toimitus yli 60 € tilauksiin
- 14 päivän palautusoikeus
- Laadukkaat materiaalit
- 100% suomalainen yritys

Selaa valikoimaamme ja löydä sinulle sopiva hauska paita!

## VAIHE 4: Tuotesivun SEO-malli

### Title-tagi:
`{Tuotenimi} – Osta {Kategoria} | Huumorikauppa`

### Meta description:
`{Tuotenimi} – {lyhyt kuvaus}. Ilmainen toimitus yli 60 €. 14 pv palautusoikeus. Tilaa nyt!`

### Rakenne:
1. **Murupolku** (BreadcrumbList schema)
2. **H1:** Tuotenimi
3. **Hinta** + alennusbadge
4. **Väri- ja kokovalitsin**
5. **Lisää koriin -painike**
6. **Trust badges** (toimitus, palautus, maksu)
7. **Tuotekuvaus** (jäsennelty H3-otsikoilla)
8. **Kenelle sopii** -osio
9. **FAQ** (ProductFAQ schema)
10. **Samankaltaiset tuotteet** (sisäiset linkit)

### Product Schema (JSON-LD):
```json
{
  "@context": "https://schema.org",
  "@type": "Product",
  "name": "...",
  "description": "...",
  "image": "...",
  "brand": { "@type": "Brand", "name": "Huumorikauppa" },
  "offers": {
    "@type": "Offer",
    "price": "...",
    "priceCurrency": "EUR",
    "availability": "https://schema.org/InStock",
    "shippingDetails": {
      "@type": "OfferShippingDetails",
      "shippingDestination": { "@type": "DefinedRegion", "addressCountry": "FI" },
      "deliveryTime": { "@type": "ShippingDeliveryTime", "handlingTime": { "minValue": 3, "maxValue": 10 } }
    }
  }
}
```
